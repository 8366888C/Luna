## The Short Answer

- **Flexbox** = One-dimensional layouts (row OR column)
- **Grid** = Two-dimensional layouts (rows AND columns)

## Flexbox Use Cases

### Navigation Menus

```css
.nav-links {
  display: flex;
  gap: 1rem;
  justify-content: space-between;
}
```

### Card Content Alignment

```css
.card {
  display: flex;
  flex-direction: column;
  justify-content: space-between;
}
```

### Centering Anything

```css
.centered {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

## Grid Use Cases

### Page Layout

```css
.page {
  display: grid;
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
}
```

### Photo Gallery

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 1rem;
}
```

### Dashboard Layout

```css
.dashboard {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
```

## Combining Both

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

.card {
  display: flex;
  flex-direction: column;
}
```

## Quick Reference

| Layout | Use |
|--------|-----|
| Nav bar | Flexbox |
| Form inputs | Flexbox |
| Card | Flexbox |
| Page layout | Grid |
| Gallery | Grid |
| Timeline | Grid |
