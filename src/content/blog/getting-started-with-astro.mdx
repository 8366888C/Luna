## What is Astro?

Astro is a modern static site generator (SSG) and web framework that lets you build faster, more content-focused websites. It ships **zero JavaScript by default**, resulting in lightning-fast page loads.

### Key Features

- **Island Architecture**: Only hydrate the interactive components you need
- **Framework Agnostic**: Use React, Vue, Svelte, or plain HTML/CSS
- **Content Collections**: Organize and type-check your markdown content
- **Built-in Optimizations**: Automatic image optimization, CSS bundling, and more

## Getting Started

To create a new Astro project, run:

```bash
npm create astro@latest
```

This will guide you through setting up your project with sensible defaults.

### Project Structure

```
src/
├── components/     # Reusable UI components
├── content/        # Markdown and MDX content
├── layouts/        # Page layout templates
├── pages/          # Route handlers and pages
└── styles/         # Global styles
```

## Why Choose Astro?

Astro is perfect for:

1. **Content-focused websites** - blogs, documentation, portfolios
2. **Marketing sites** - landing pages, product showcases
3. **E-commerce** - product pages with fast load times

> The best part about Astro is that you can progressively enhance your site with interactivity only where needed.
