## What is a Second Brain?

A digital system for organizing your knowledge, ideas, and learnings.

### Benefits

1. Capture ideas before you forget them
2. Make connections between concepts
3. Build on previous work
4. Share knowledge with others

## The PARA Method

### Projects
- Work projects with deadlines
- Active goals

### Areas
- Ongoing responsibilities
- Areas of focus

### Resources
- Reference materials
- Interests

### Archives
- Inactive projects
- Old reference materials

## Tools to Consider

- **Obsidian** - Markdown-based, local-first
- **Notion** - Full-featured workspace
- **Readwise** - Capture from anywhere
- **Heptabase** - Visual thinking

## Implementation

### Daily Notes

```markdown
# 2024-03-15

## Learnings
- tRPC provides end-to-end type safety

## Ideas
- Build a personal wiki

## Todo
- [ ] Review PR #123
```

### Fleeting Notes
Quick captures that get processed later.

### Permanent Notes
Polished, interconnected knowledge.
